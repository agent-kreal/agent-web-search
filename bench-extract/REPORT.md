# Бенчмарк экстракторов: local-каскад vs сервисные (27.08.2026)

35 живых URL × 9 сценариев × 8 экстракторов (258 пар) + офлайн-проверка ядра на
WCXB (2008 стр). План: `~/.claude/plans/snazzy-churning-pixel.md`; датасет:
`dataset.jsonl`; прогоны: `results/raw.jsonl`, `results/grade.json`,
`results/scores_*.jsonl`.

## TL;DR

1. **local-auto закрывает 80% датасета (28/35) бесплатно и с лучшим качеством**:
   0.71–0.76 по всем закрытым сценариям против 0.33–0.58 у сервисных. Провалы
   local — ровно ожидаемые: pdf (unsupported), antibot (by design), SO (blocked).
2. **Сервисные точечны, не универсальны**: pdf → **jina** (0.28; единственный с
   markdown-заголовками из PDF), antibot/CF → **firecrawl** (0.20; единственный
   с реальным контентом), остальное local закрывает сам.
3. **Ядро валидировано** (часть A, WCXB): наш markdown-конфиг F1 0.832 ≈ vanilla
   trafilatura 0.829 — тюнить нечего, слабые места ядра известны (product/
   listing/forum 0.6–0.7).
4. **tavily как экстрактор опасен в цепочке**: ok=100%, но 17% «успехов» —
   пустые (<200 симв.), на wiki TOC вытесняет тело статьи. Пустой вывод при
   ok=true — фолбэк должен проверять длину, а не только статус.
5. **v2-кандидаты по цифрам**: browser-тир — главный тормоз (медиана 5.5 с,
   p90 25.7 с → CDP-daemon); unfenced-код на react-виджетах; HN-таблицы
   (s.gif-мусор у trafilatura); потеря заголовков на postgres-страницах.

## Методика

- **Экстракторы**: `local-auto/http/curl/browser` (каскад `local-extract/`,
  напрямую venv, бесплатно) — `firecrawl`, `tavily` (1 кредит/вызов),
  `jina` (keyless), `parallel` ($-грант, подмножество 12 URL).
- **Метрики**: сниппет-золото по образцу WCXB — `with_recall` (доля
  обязательных фраз, матч по нормализованным head+mid), `without_rate`
  (просочившийся бойлерплейт); LLM-джадж (рубрика ReaderLM-v2 Critique:
  structure/clean/content 0–2) — 9 субагентов, по одному на сценарий;
  объективщина: ok%, empty%, wall, chars, структура-признаки.
- **quality = 0.5·with_recall + 0.35·judge_mean + 0.15·(1−without_rate)**;
  judge_mean = mean(structure, clean, content)/6. Считается только по ok-парам,
  поэтому рядом с quality всегда смотреть ok/n.
- **Нормализация матчинга** (`grade.py:norm`): HTML-entities, `<br>`-вставки
  (firecrawl рвёт paulgraham экранированными переносами), дефис-переносы PDF
  (tavily: «re-ceptors») — убираются до общей зачистки, симметрично для фразы
  и текста.

### Оговорки (читать цифры с ними)

- **Self-bias with_recall у local**: обязательные фразы выбирались из полного
  local-auto вывода → wr 96.4% у local завышен, у сервисных занижен. Поэтому
  вес судьи 35% и вердикты джаджей (глазами по окнам) приоритетнее wr при
  расхождении.
- **Окна head+mid (2k+2k из 32k)**: у сервисных навигационные префиксы смещают
  контент за пределы окон → wr недооценивает сервисные (джадж article-en
  показал: firecrawl на paulgraham контент цел, фразы рвались `<br>`; wiki-тела
  у tavily реально вытеснены — подтвердлено глазами).
- **Малые n**: parallel на сценариях n=1–2 (spa-app 0.77 — это один photopea);
  firecrawl forum 0.73 — n=1 из 4 ok (3 форумных URL у него упали).
- **parallel** возвращает пересказы с «...»-эллипсисами (chars_med 3688 против
  11–25k у остальных) — это не экстрактор, а summarizer; для fetch-задач
  «полного текста» проигрывает всем.
- Джадж-«то же» 42× — идентичность выводов local-тиров друг другу (проверено).

### Тиры local-auto по сценариям

`http` закрывает: static-docs, article-en/ru, docs-js, tables (100%) и 3/4
forum. `browser` нужен: 3/4 spa-app (excalidraw, mempool, photopea; gazeta —
CSR-пустышка, и там http). Провалы: SO (blocked), antibot×3, pdf×3.

### Судейские вердикты по сценариям

- **article-ru**: local идеален на habr/rbc; firecrawl/tavily на rbc — только
  меню (0/0/0). RU-медиа = однозначно local.
- **docs-js**: local clean 2.00 везде; jina теряет код-ограждения (codeblocks
  0.5 против 2.5 у local); firecrawl structure 1.80 но clean 1.00 (нав-шум);
  react.dev sandpack-виджеты — unfenced-код у trafilatura (v2).
- **forum**: jina — лучшая structure (явная разметка постов); local идеален на
  семантичном HTML (Discourse, LOR); HN у local — s.gif-таблицы (мусор, судья
  0/0/1); SO блок у всех; firecrawl упал на 3 форумных URL из 4.
- **antibot**: только firecrawl реален (g2.com полностью); «успехи» tavily =
  0 символов/пустота, jina = challenge-страница.
- **pdf**: jina лучший (заголовки из PDF), firecrawl ломается repetition-loop
  на сложных макетах (инструкция AAO-HNSF: циклический повтор FAQ-таблицы),
  tavily склеивает всё в blob с дефис-переносами.
- **tables**: все 3 страницы — «таблицы» из `<pre>`-консолей (настоящих
  HTML-таблиц 0); local лучший, но postgres-страница потеряла все заголовки
  (structure 1); tavily склеивает многострочные консоли в кашу (structure 0).
- **spa-app**: local тянет полный контент browser-тиром, но плоско (structure
  0 у CSR-дампов); сервисные структурнее; parallel на photopea 0.77 — но n=1
  и пересказ-стиль.

## Сценарий → экстрактор (главная таблица решений)

| сценарий | выбор | почему |
|---|---|---|
| обычные статьи/доки/RU-медиа/таблицы | **local** (дефолт) | 0.71–0.76, free, 1.3 с |
| SPA (CSR-приложения) | **local** (browser-тир), сервис — если нужна структура | контент полный, но плоский |
| PDF | **jina** → tavily | markdown-заголовки; firecrawl нестабилен на макетах |
| Cloudflare/antibot | **firecrawl** | единственный с реальным контентом |
| форумы | **local**; HN — ничего не помогает | семантичный HTML clean; SO блок у всех |
| пересказ vs полный текст | никогда parallel для fetch | «...»-эллипсисы, 3.7k chars |

## Экономика

- local-auto ok на 80% датасета → **~80% fetch-запросов не тратят кредиты**.
  На месячном объёме firecrawl 2000 кредитов это ≈ 1600 сэкономленных
  (остаток после бенча: 1981; tavily 867; parallel ~12 вызовов ≈ $0.5–1 из
  $18.46).
- Сервисные остаются специализированным резервом на ~20% URL (pdf+antibot+
  сложные форумы) — там, где local by design бессилен.

## v2-кандидаты (по цифрам, не срочно)

1. **CDP-daemon / patchright для browser-тира**: медиана 5.5 с, p90 25.7 с —
   каждый SPA-URL платит launch-ценой браузера. Daemon держит контекст.
2. **Unfenced-код у trafilatura** на react-виджетах (sandpack) — код есть, но
   без ```-ограждений; решается пост-обработкой или своим extraction-режимом.
3. **HN-подобный legacy-HTML**: s.gif-таблицы — претрейн trafilatura не любит
   таблиц-вёрстку; точечный кейс, не приоритет.
4. **Заголовки postgres-доков**: потеря `Description`/`Parameters`-заголовков
   при сохранении синопсиса — глянуть, что за разметка.
5. **curl-тир**: подтвердил право на жизнь — закрывает то же, что http
   (там, где http не пускают по TLS-отпечатку), медиана 1.0 с.

## Черновик дописки в SKILL.md (`/web-search`, секция fetch)

Таблица выбора провайдера для агента (детерминированные правила поверх
каскада; агент может осознанно звать `--provider X`):

- PDF-ссылка → `--provider jina` (fallback tavily), НЕ firecrawl.
- Cloudflare-challenge/antibot-сайт → `--provider firecrawl`.
- RU-медиа, статьи, доки → local-каскад (дефолт `fetch` без `--provider`).
- Нужна структура SPA-дампа → jina/firecrawl поверх local.
- Никогда parallel для полного текста (пересказы с «...»).
- После tavily в цепочке проверять длину вывода: 17% «успехов» — пустые.
