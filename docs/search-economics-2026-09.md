# Экономика веб-поиска для агента: три категории, цены, вертикаль поставки

Дата: 2026-09-09. Все цены проверены в этот день по первоисточникам (ссылки внизу).
Единица расчёта: «поисковая операция» = 1 поисковый вызов агента; «с контентом» = + экстракт топ-3 страниц (80% local-каскад бесплатно, 20% firecrawl по $0.8–2.5/1k страниц — тарифы Hobby/Standard extra credits).

## TL;DR

- **Free-пулы wsearch (~12k/мес) — оптимум до ~10k операций/мес.** Дальше первое платное дно — Serper $1/1k prepaid.
- **«Срезать посредника» в SERP-вертикали не работает**: Google CSE напрямую $5/1k с капом 10k/день, а Serper перепродаёт ту же Google-выдачу за $1/1k. Посредник — самый дешёвый слой.
- **AI-поисковики (Tavily $8–16/1k) — это плата за пайплайн** (выдача+контент+реранк), а не за поиск. Наша связка «SERP + local extract» = $2.5–4/1k, ×3–6 дешевле.
- **Self-hosted SearXNG** ≈ $0.5–1/1k (только residential-трафик), но требует прокси и backoff-логики; место — бесплатное дно каскада, не основной канал.
- **RU-исключения**: Яндекс отложенные $0.33/1k (батчи!), инфоконтексты ~$12–16/1k (RU-глубина + дословные выдержки, уровень Tavily).

## Вертикаль поставки (3 слоя)

```
Индекс (Google / Яндекс / Brave / свой краулер)
  → голый SERP-доступ        Serper $1, DataForSEO $0.6, Google CSE $5, Яндекс синхр ~$5.2
  → «AI-обвязка»             Tavily $8–16, Exa $7–8, инфоконтексты Яндекса $12–16, Linkup $5–6
```

Декомпозиция цены Tavily: ~$1 SERP-себестоимость + $2–4 LLM-обвязка (реранк/чистка на их GPU) + маржа ×2. Своя схема срезает обе позиции: extract — локально бесплатно, LLM — в своей квоте.

## Категории: функционал / плюсы / минусы / риски

### 1. AI-поиск API (Tavily, Exa, Linkup, инфоконтексты)
- **Плюсы**: ноль инфраструктуры; latency 1–2 сек; 0 ошибок фетча; готовые чанки для RAG; семантика (Exa); у инфоконтекстов — цитируемость и RU-глубина (gov.ru, регионы).
- **Минусы**: платно с первого запроса; контент — их выборка из их кэша (не всегда свежая); RU-качество у западных слабое; чёрный ящик.
- **Риски**: смена прайса, vendor lock; на 50k+ счёт растёт быстрее всех.
- **Побеждает когда**: нет своей экстракции (прототип) или RU-QA-сценарий (инфоконтексты).

### 2. SERP API + свой экстракт (наш вариант)
- **Плюсы**: Google-ранжирование (лучший релеванс); свежий контент (живой fetch); агент сам решает, что читать; дёшево; prepaid; экстракция уже построена (local-каскад).
- **Минусы**: экстракцию надо поддерживать (вёрстка/антибот дрейфуют, ~пара часов/мес); latency SERP+fetch; новичку неделя-две на построение.
- **Риски**: ToS-серость прокси Google; 403 на антибот-сайтах (лечится firecrawl-тиром); нет RU-глубины Яндекса.

### 3. Self-hosted SearXNG (+residential)
- **Плюсы**: ~$0 подписки; полный контроль; приватность; мультидвижковость (один лёг — другие отвечают).
- **Минусы**: качество ниже чистого Google; поддержка (прокси, капчи, `/stats/errors`); нужен отдельный чистый IP (НЕ VPN-выход — репутация делится); latency.
- **Риски**: капчи апстримов при высоком QPS; ToS всех движков разом; на 100k/мес время инженера — главная статья.
- **Законное место в каскаде**: бесплатное keyless-дно между linkup и ddg; при низком QPS (1 req / 2–3 сек) одиночный IP живёт месяцами.

## SearXNG: уроки бана и настройка

**Почему банят**: движки капчат IP инстанса; агент без backoff после первой ошибки превращается в атаку и сжигает репутацию IP. VPN-выход и краулинг на одном IP нельзя смешивать.

**Ключевые настройки** (docker, приватный инстанс):
```yaml
# settings.yml
server: { secret_key: "...", limiter: false }   # приватный — бот-детекция не нужна
search: { formats: [html, json] }               # JSON API для агента
engines:
  - { name: google, disabled: true }            # самый банный движок
  - { name: startpage, disabled: true }
outgoing:
  request_timeout: 6
  proxies:
    all://: [http://login:pass@gw.dataimpulse.com:823]   # ротация на их стороне
```

**IP-роутинг**: gateway-endpoint у residential-провайдера (DataImpulse $1/GB pay-as-you-go, Webshare $1.40/GB, IPRoyal ~$1.75/GB). Один URL — IP меняется сам на каждый запрос; sticky-сессии 30–120 мин через `Session_xxx` в username; гео через `Country_ru`. SERP-страница ~100–200 KB, SearXNG бьёт в 3–4 движка → ~0.5–1 GB на 1k запросов ≈ **$0.5–1/1k**. Datacenter-прокси для поисковиков бесполезны (мгновенная капча).

**Backoff-паттерн агента** (главный урок):
```
429 / unresponsive_engines > 50% → cooldown инстанса 30–60 мин
таймаут                          → 1 ретрай через 5–10 сек (джиттер)
5xx                              → 10с → 30с → 90с → стоп
капча-признак                    → пауза на часы; при ротации лечится само (след. запрос = новый IP)
retry budget                     → max 2–3 попытки, потом фолбэк вниз по каскаду
```
SearXNG сам suspend-ит движок после серии ошибок; в JSON есть `unresponsive_engines`.

**Hosted SearXNG**: PikaPods ~$1.80–2.40/мес, InstaPods $3, Elestio от ~$10. Снимает админку, но не риск бана (shared IP узла, лимиты на нагрузку).

## Инфоконтексты Яндекса (RU-QA-слой)

SERP + дословные выдержки (~500 токенов/док, до 20 доков, потолок 2048/док) одним вызовом; регион RU. Заменяют fetch-цикл: 0 заходов на сайты, 0 ошибок 403, gov.ru/регионы из индекса. Отличия от своего экстракта: выдержка из кэша (свежесть зависит от переобхода), кусок выбирает их алгоритм (всю страницу не увидеть), зато нет антибот-фейлов. Правило Полякова: QA-запросы → включать; мониторинг/таблицы → отложенный режим без выдержек. Для wsearch смысл появляется от ~500 RU-QA-запросов/мес, ниже — дешевле Tavily free-тир.

## Рецепт по объёмам

| Объём | Рецепт |
|---|---|
| до ~10k/мес | free-пулы wsearch + ddg-дно (текущий стек) |
| 10–50k/мес | free-пулы + Serper $50 prepaid (50k выдачи, кредиты 6 мес) |
| 50k+/мес | Serper (интерактив) + Яндекс отложенные (RU-батчи) + DataForSEO на пиках |
| RU-QA точечно | инфоконтексты Яндекса |
